# Project BELAJAR-LARAVELL

Aplikasi web berbasis Laravel yang mencakup fitur sistem autentikasi, dashboard manajemen data (CRUD), dan integrasi peta interaktif.

---

## 🚀 Fitur Utama

- **Sistem Autentikasi**: Fitur Register, Login, & Logout pengguna
- **Dashboard Admin**: Tampilan panel antarmuka admin yang responsif
- **Manajemen Data (CRUD)**:
  - CRUD Data Produk
  - CRUD Data Kategori
  - CRUD Data User / Pengguna
- **Integrasi Peta Interaktif**: Peta lokasi berbasis **Leaflet.js** & **ArcMap**
- **Visualisasi Data**: Grafik statistik menggunakan **Chart.js**

---

## 🛠️ Teknologi & Resource yang Digunakan

- **Framework**: Laravel
- **Bahasa Pemrograman**: PHP, JavaScript, HTML, CSS
- **Database**: MySQL
- **Styling & UI**: Bootstrap / SB Admin 2
- **Library**:
  - Leaflet.js (Peta)
  - Chart.js (Grafik)
